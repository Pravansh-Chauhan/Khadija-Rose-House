# Khadija Rose House

متجر إلكتروني عربي لبوكيهات الورد الساتان المصنوعة يدوياً. يضم واجهة للزبائن، مصمّم بوكيه باختيارات مصوّرة، وسلة مشتريات ولوحة إدارة منفصلة.

## محتويات المشروع

```text
Khadija Rose House/
├── README.md
└── الواجهة/
    ├── index.html                 صفحة المتجر
    ├── admin.html                 صفحة إدارة المتجر
    ├── storefront.js              سلوك المتجر والمصمّم والسلة والطلبات
    ├── admin.js                   سلوك لوحة الإدارة
    ├── supabase-config.js         إعداد اتصال Supabase
    ├── supabase-client.js         إنشاء عميل Supabase
    ├── supabase-schema.sql        الجداول والسياسات ودوال الطلبات
    └── assets/
        ├── storefront.css
        ├── admin.css
        └── options/                صور التغليف والأشرطة
```

## المتطلبات

- مشروع [Supabase](https://supabase.com/) لتخزين إعدادات المتجر والطلبات وتسجيل دخول الإدارة.
- Python 3 أو أي خادم ملفات ثابتة محلي للتطوير.
- اتصال بالإنترنت لتحميل مكتبة Supabase والخطوط والصور الخارجية المستخدمة في التصميم.

## إعداد Supabase

1. أنشئي مشروعاً جديداً في Supabase.
2. افتحي **SQL Editor** وشغّلي محتوى الملف `الواجهة/supabase-schema.sql` لإنشاء الجداول والسياسات وإعدادات البداية.
3. من **Authentication → Users** أنشئي مستخدم الإدارة بالبريد الإلكتروني وكلمة المرور. لا تضعي بيانات الدخول في ملفات الموقع.
4. انسخي معرّف المستخدم (UUID) من صفحة المستخدم، ثم أضيفيه إلى عضوية الإدارة من SQL Editor:

   ```sql
   insert into public.store_admins (user_id)
   values ('00000000-0000-0000-0000-000000000000')
   on conflict (user_id) do nothing;
   ```

   استبدلي UUID المثال بالمعرّف الحقيقي للمستخدم قبل تشغيل الاستعلام.

5. من إعدادات المشروع انسخي **Project URL** و**anon/public key**، ثم ضعيهما في `الواجهة/supabase-config.js`:

   ```js
   window.KRH_SUPABASE_CONFIG = Object.freeze({
       url: 'https://YOUR-PROJECT.supabase.co',
       anonKey: 'YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY'
   });
   ```

   المفتاح العام مخصص للاستخدام في المتصفح؛ السياسات في قاعدة البيانات هي التي تقيّد الصلاحيات. **لا تضعي مفتاح `service_role` أو أي سرّ إداري في ملفات الواجهة.**

6. سجّلي الدخول من `admin.html` بالحساب الذي أنشأتِه وأضيفتِه إلى `store_admins`. من لوحة الإدارة حدّثي رقم WhatsApp الدولي، الأسعار، المنتجات، الصور ومعلومات المتجر قبل استقبال الطلبات.

تسمح قاعدة البيانات للزوار بقراءة إعدادات المتجر، لكن إنشاء الطلبات يتم عبر الدالة `place_store_order` التي تتحقق من حالة المتجر والخيارات المتاحة وتحسب السعر. قراءة الطلبات وتعديل المتجر محصورة بحسابات الإدارة المسجلة.

## التشغيل محلياً

افتحي PowerShell في مجلد `الواجهة` وشغّلي:

```powershell
python -m http.server 8000
```

ثم افتحي:

- المتجر: <http://127.0.0.1:8000/>
- لوحة الإدارة: <http://127.0.0.1:8000/admin.html>

أوقفي خادم التطوير باستخدام `Ctrl+C`. يُفضّل تشغيل الموقع عبر HTTP محلياً بدلاً من فتح ملفات HTML مباشرة، خصوصاً عند اختبار اتصال Supabase.

## الميزات

- واجهة عربية متجاوبة باتجاه RTL، مع المجموعة الجاهزة وفلاتر اللون والحجم.
- مصمّم بوكيه من أربع خطوات: عدد الوردات، اللون، التغليف والشريط، والإضافات؛ تعرض الخيارات بصور وملخصاً وسعراً تقديرياً.
- سلة محفوظة في `localStorage` على جهاز الزبون، وإرسال تفاصيل الطلب إلى قاعدة البيانات ثم فتح WhatsApp برسالة جاهزة.
- لوحة إدارة مستقلة للدخول الآمن وإدارة الطلبات والمنتجات والأسعار ومحتوى المتجر وخيارات المصمّم.
- خيارات الألوان والورق والأشرطة قابلة للإضافة والتعديل والتفعيل والتعطيل والحذف. يمكن تغيير صور الإضافات أيضاً.
- الصور الموجودة داخل `الواجهة/assets/options/` تُضمّن مع ملفات الموقع.

## إدارة صور خيارات المصمّم

من لوحة الإدارة، أضيفي أو عدّلي رابط صورة **HTTPS**، أو مساراً نسبياً داخل مجلد `الواجهة` يبدأ بـ `assets/`، مثل:

```text
assets/options/papers/paper-01.avif
assets/options/ribbons/ribbon-01.jpeg
```

لإضافة صور جديدة محلياً، ضعيها داخل `الواجهة/assets/` ثم استخدمي مسارها النسبي في لوحة الإدارة، وتأكدي من نشر الملف مع الموقع. لوحة الإدارة تحفظ المسار أو الرابط فقط؛ **لا ترفع الملفات من الجهاز إلى التخزين السحابي**.

## النشر

ارفعي محتويات مجلد `الواجهة` كما هي إلى استضافة مواقع ثابتة تدعم HTTPS، مع الحفاظ على مجلد `assets` ومسارات الصور. حدّثي `supabase-config.js` بإعدادات المشروع، ثم أضيفي نطاق الموقع إلى إعدادات عناوين الموقع وإعادة التوجيه في Supabase Authentication وفق نطاق النشر.

اختبري بعد النشر:

1. تحميل المنتجات وخيارات المصمّم والصور.
2. تسجيل الدخول إلى الإدارة وتعديل خيار، ثم التأكد من ظهوره للزوار.
3. إنشاء طلب تجريبي والتأكد من تسجيله واحتساب المجموع وفتح رسالة WhatsApp.

## ملاحظات

- بيانات Supabase غير موجودة افتراضياً؛ تبقى ميزات الإدارة والطلبات غير متصلة حتى إكمال الإعداد.
- عربة التسوق محلية على متصفح الزبون، بينما تُسجل الطلبات في Supabase.
- تأكيد الطلب لا يرسل رسالة WhatsApp تلقائياً؛ يفتح رسالة مُعدّة ليكمل الزبون إرسالها.
- الأسعار المعروضة تقديرية؛ تعيد قاعدة البيانات حساب أسعار المنتجات والتصاميم عند إنشاء الطلب.
